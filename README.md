# Power Platform Process Automation

## Overview

A process automation solution built using Microsoft Power Apps, Power Automate, SharePoint, and Microsoft Copilot.

The solution automates service request submission, vendor matching, document generation, SharePoint folder creation, approval processing, and notifications.

## Technologies

- Microsoft Power Apps
- Power Automate
- SharePoint
- Microsoft Copilot
- Microsoft Word Templates

## Key Features

- Power Apps request submission form
- Form validation
- Automated SharePoint record creation
- Dynamic vendor matching
- Automated document generation
- SharePoint folder and attachment management
- Approval workflow
- Automated approval/rejection notifications

## Business Problem

The original process relied on hardcoded vendor and topic-area matching logic within Power Automate. The improved solution uses SharePoint-based configuration to make vendor and topic-area updates easier to maintain.

## Solution Architecture

User
→ Power Apps
→ Power Automate
→ SharePoint
→ Vendor Matching
→ Document Generation
→ Approval
→ Notification
